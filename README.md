# 成为传奇 · Become a Legend

一个纯前端的像素风足球生涯模拟游戏。你扮演一名 17 岁的青训球员，通过每周的安排与一场场比赛，
从无名少年成长为世界足球先生。

**核心玩法**：比赛中会随机出现「高光时刻」（射门 / 传球 / 盘带 / 防守），
你需要用鼠标或手指**在球场上划出一条轨迹**来完成这次操作。
轨迹的**终点、形状、长度**都会被判定，而你的能力值直接决定容错圈大小、划动时间与对手的抢断范围。

---

## 运行

不需要构建、不需要联网、不需要服务器：

```
双击 index.html
```

（全部使用传统 `<script>` 标签，因此 `file://` 直接打开即可运行；存档写在 localStorage。）

如果想用本地服务器：
```
python -m http.server 8080     # 然后访问 http://localhost:8080
```

## 操作说明

| 场景 | 你要做的 | 判定 |
| --- | --- | --- |
| **射门** | 从球出发划出射门轨迹，终点落在黄色光圈（球门死角） | 终点精度 / 轨迹贴合度 / 划动长度；门将猜对边才可能扑出 |
| **传球** | 划出传球路线，终点落在蓝色接球圈（空档队友的提前量位置） | 是否选对人、路线是否穿过防守球员、提前量是否准 |
| **盘带** | 划出跑动路线，绕开红色抢断圈，终点落在黄色区域 | 沿轨迹实时推进并检测碰撞 |
| **防守** | 划出拦截路线，在对手前进路线（黄色虚线预览）上截住他 | 你的跑速与对手跑速的时空交汇点 |

- 起手必须**靠近球**（球上会有一个脉冲光圈提示）。
- 每种场景都有**限时**，拖太久会判定失败。
- 结果分为 **精彩 / 成功 / 失败** 三档，直接影响赛后评分与本场成长。

## 系统

**属性（6 项）**：射门 / 传球 / 盘带 / 防守 / 速度 / 体能，1–99。
综合评分按位置加权（7 个位置：中锋、边锋、前腰、中前卫、后腰、边后卫、中后卫）。

**能力值如何影响操作难度**
- 射门：容错圈更大、门将判断正确率更低、扑救范围更小
- 传球：终点容错与路线容错更大
- 盘带：对手抢断圈更小
- 防守：拦截范围更大、对手跑动路线的预览更远
- 速度：划动时间更充裕、盘带/防守时移动更快
- 体能：体力消耗更慢，并计入实际发挥值

体力、士气、状态、队内关系都会修正「实际发挥值」，实际的对手强度决定场景难度。

**一个赛季**
1. 每周选择一个安排：6 种属性特训 / 休息 / 队友聚会 / 商业活动
2. 随机触发决策事件（更衣室风波、赞助商、带伤出战、经纪人施压……）
3. 第 3–4 步：赛前预测 → 比赛（亲手操作，或快速模拟）→ 赛后评分与成长
4. 赛季末：名次、个人荣誉（最佳射手 / 助攻王 / MVP / 最佳新人 / 世界足球先生）、属性成长、转会报价
5. 年龄 +1，进入下赛季；36 岁退役，生成生涯履历

**其他**：联赛积分榜与双循环赛程、伤病与伤停、身价/周薪、投资商店（私人教练 / 康复师 / 公关团队 / 定制战靴）、localStorage 自动存档。

## 文件结构

```
index.html          页面骨架
styles.css          像素风 UI（硬边框 + 分段属性条 + 复古配色）
src/data.js         静态数据：属性、位置、俱乐部、训练、事件、商店、荣誉
src/pixel.js        像素渲染：球场 / 顶视球员 / 足球 / 轨迹 / 虚线提示 / 像素头像
src/state.js        游戏状态：成长公式、联赛与赛程、赛季结算、荣誉、转会、存档
src/scenes.js       轨迹小游戏框架（运行器 / 判定）+ 射门 + 传球
src/scenes2.js      盘带 + 防守 + 场景工厂
src/match.js        比赛引擎：出场判定、场景调度、比分、评分
src/ui.js           界面：主菜单 / 创建球员 / 生涯主界面 / 事件 / 商店
src/ui2.js          界面：赛前 / 比赛 / 赛后 / 赛季结算 / 退役
src/main.js         启动入口
tools/selftest.js   无浏览器自检
```

### 相机与坐标
世界坐标固定为 256×160，相机只显示右侧进攻区域
（`P.VX=56, P.VY=18`，画布 200×124）。所有场景逻辑写在世界坐标里，
绘制时统一 `translate(-VX,-VY)`，输入时反向换算，UI 层（计时条 / 结算横幅）画在屏幕坐标。

## 自检

```
node tools/selftest.js
```

用假的 canvas 上下文加载全部脚本，做三件事：
1. 320 次场景结算（4 种场景 × 4 档难度 × 4 档能力 × 5 种划动方式），检查异常与结算
2. 对比「认真划」与「乱划」的成功率，验证操作技巧确实影响结果
3. 6 个位置各跑 3 个赛季的完整生涯（含训练、事件、比赛、转会、赛季结算、界面渲染）
